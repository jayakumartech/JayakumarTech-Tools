# JayakumarTech Tools

A mobile-first directory for 20 planned free web tools by **jayakumartech**.

## Included
- Responsive dashboard for phones, tablets and desktops
- Tamil / English toggle
- Dark / light theme preference
- Search and category filters
- 20 tool roadmap cards
- GitHub Pages compatible static files

## Important status note
All 20 cards are roadmap entries and are intentionally marked **Coming soon**. They are not represented as working tools until their separate repositories are built, tested and deployed.

## Deploy on GitHub Pages
1. Open repository **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`.
4. Save and wait for the Pages deployment.
