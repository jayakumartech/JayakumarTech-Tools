# Barcode & Label Studio

A browser-based barcode label designer for small shops and product inventory.

## Features
- Generate CODE 128, EAN-13, UPC-A, CODE 39 and ITF-14 barcodes.
- Product name, SKU/barcode value, optional price and extra text.
- Label presets: 50×30 mm, 40×25 mm, 60×40 mm, plus custom dimensions.
- Print up to 200 copies per generation.
- Toggle product name, barcode value and price.
- Responsive interface and dark/light theme.

## Requirements and limitations
JsBarcode 3.11.6 loads from cdnjs, so barcode generation requires an internet connection. Actual printed size and alignment depend on printer settings, margins and label stock. Print at 100% / Actual size. This tool creates visual barcodes; it does not register product identifiers with GS1 or validate ownership of a code. Confirm the printed barcode with a scanner before bulk printing.
