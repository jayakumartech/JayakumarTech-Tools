# Tamil Typing Studio v1.0

Tamil typing utility for JayakumarTech Tools.

## Features
- Tanglish-to-Tamil phonetic transliteration using Google Input Tools (internet required).
- Candidate suggestions when available.
- On-screen Tamil character keyboard that works offline.
- Character, word and line counts.
- Copy, select all, clear and UTF-8 TXT download.
- Dark/light theme and mobile responsive layout.

## Install
Extract this folder to `tools/tamil-typing-studio/` and open `index.html`.

## Notes
Online transliteration requires internet and depends on the third-party service. The virtual keyboard and text editing work offline. This is a typing utility, not an official Tamil99 keyboard implementation or government service.
