# WebDev Toolbox v1.0

A mobile-friendly browser workspace for writing HTML, CSS and JavaScript.

## Features
- Separate HTML, CSS and JavaScript editors
- Live preview in a sandboxed iframe
- Sample project, clear and copy-current-editor actions
- Full-screen preview and dark/light theme
- Download current project files (HTML, CSS and JS)
- Client-side only; no server upload

## Install
Extract this folder to `tools/webdev-toolbox/` and open `index.html`.

## Limitations
This is a lightweight editor, not a full IDE. It does not include syntax highlighting, autocomplete, terminal, package installation or multi-file project management. Preview code runs in a sandboxed iframe; do not run code you do not trust.
