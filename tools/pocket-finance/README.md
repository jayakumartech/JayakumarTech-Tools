# Pocket Finance — JayakumarTech Tools

Mobile-friendly personal income and expense tracker.

## Features
- Income and expense entries with date, category and payment method
- Monthly income, expense, balance and savings-rate summary
- Category budgets with progress indicators
- Search and delete transactions
- Export the selected month to CSV
- Dark/light appearance
- Browser localStorage; no account or server upload

## Use
Open `index.html` in a modern browser or publish this folder with GitHub Pages.

## Data note
Entries are stored only in this browser on this device and do not sync. Export CSV backups regularly. Clearing browser storage can erase data. This is a tracking utility, not financial, tax or investment advice.
