# File Utility Box

Mobile-friendly client-side file utilities.

## Features
- Create ZIP archives from multiple selected or dropped files.
- Open ZIP archives and download selected entries individually.
- Inspect file name, MIME type, size and last-modified date.
- Encode and decode UTF-8 text as Base64.
- Responsive dark/light interface.

## Requirements
ZIP functionality loads JSZip 3.10.1 from cdnjs and therefore requires an internet connection. File inspection and text Base64 conversion work locally. Large archives can use substantial device memory.

## Privacy
Files are processed in the browser and are not uploaded to a server by this app. Only open ZIP files from trusted sources. This tool does not scan files for malware.
