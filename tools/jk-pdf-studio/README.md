# JK PDF Studio

Mobile-first browser PDF tools for JayakumarTech Tools. Uses PDF-Lib from a CDN.

## Implemented in this release
Merge, split (one page per output), extract, delete, rotate, reorder, watermark, page numbers, metadata viewer, and images-to-PDF. Re-save is best-effort and is not guaranteed to compress.

## Not included yet
PDF-to-images export, password protection/encryption, and password unlocking. This tool does not crack passwords. Do not rely on this release to encrypt confidential files.

Files are processed in the browser; no JK server upload is used. CDN scripts are loaded from unpkg. MIT License.
