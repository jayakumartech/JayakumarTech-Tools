# India Tax Calculator v1.0

Responsive browser tool to compare simplified old/new regime estimates for Tax Year 2026-27. Includes age/residential status, salary, other normal income, old-regime deductions, standard deduction assumptions, simplified resident rebates, 4% cess, dark mode and Print/Save PDF.

**Limitations:** Educational estimate only. Special-rate income is excluded from totals. Surcharge, surcharge marginal relief, detailed exemptions/HRA, capital gains, business/professional income and taxpayer-specific adjustments are not calculated. Rebate handling is simplified; verify before filing.

Official references: Income Tax Department tax rates https://wm.incometaxindia.gov.in/w/tax-rates-and-computation and Tax Year 2026-27 explanation https://www.incometax.gov.in/iec/foportal/help/all-topics/e-filing-services/objective-and-scope-new-act

All calculations run locally in the browser; no data is uploaded.
