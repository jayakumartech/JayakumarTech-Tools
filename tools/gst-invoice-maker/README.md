# GST Invoice Maker — JayakumarTech Tools

Extract this folder into `tools/gst-invoice-maker/`.

Features: business/customer details, GSTIN fields, multiple line items, HSN/SAC, quantity, rate, per-item GST percentage, intra-state CGST/SGST, inter-state IGST, no-GST mode, discount, nearest-rupee rounding, live preview, print / browser Save as PDF, local invoice save, responsive layout and light/dark theme.

Important: This is a preparation/calculation helper, not GST filing software. It does not validate GSTINs, determine tax rates, or infer place of supply. You must choose the correct tax mode and rates. Saved invoices are stored in this browser on this device and may be lost if browser data is cleared. Verify statutory invoice requirements with your accountant before issuing invoices.
