# ImageKit Pro v2.0

A mobile-first browser image workspace for JayakumarTech Tools.

## Working features
- Multiple image selection and drag/drop queue
- Local image preview and file/dimension information
- Brightness, contrast, saturation and blur controls
- B&W, sepia, vivid and soft quick filters
- Rotate 90 degrees, horizontal/vertical flip
- Crop by entering X/Y/width/height and apply the crop to export
- Resize presets and custom output dimensions with aspect-ratio lock
- Text watermark with size, opacity, position and shadow
- JPG, PNG and WebP export with adjustable quality where supported
- Download current image or export queued images individually
- English/Tamil interface toggle, light/dark theme
- Back navigation to JayakumarTech Tools

## Important limitations
- Crop is numeric-area based in this release; draggable crop handles are not included.
- Batch download triggers separate downloads, not a ZIP archive.
- GIF input is rendered as a browser image preview and export uses a still frame.
- AI background removal, AI upscaling, object removal, OCR, PDF tools, and animated GIF creation are not included in v2.0.
- EXIF metadata may not be preserved. Very large images depend on available device memory.
- Browser support varies for WebP and other image formats.

## Privacy
Image files are processed locally in the browser and are not uploaded to a server.
