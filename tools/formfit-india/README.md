# FormFit India
Mobile-first photo/signature sizing utility.

Features: passport-style and square photo presets, signature dimensions, custom pixel sizing, JPG/PNG export, quality slider, white/light-blue/original background fill, and 3×4 photo placement on a 4×6 canvas.

Important: presets are convenience starting points, not official government requirements. Always follow the exact portal specification. Background fill does not remove a person from the original background. Images are processed locally in the browser.
