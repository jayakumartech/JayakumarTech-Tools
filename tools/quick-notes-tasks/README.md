# Quick Notes & Tasks

A responsive, local-first notes and task manager.

## Features
- Create, edit and delete notes.
- Add tasks with priority and optional due date.
- Mark tasks complete; filter all, pending and completed.
- Task summary counters.
- Export and import a JSON backup.
- Dark/light theme.
- Browser localStorage persistence.

## Privacy and limitations
All data is stored in localStorage on the current browser and device. It is not encrypted and is not synced to other devices. Clearing browser storage can delete it; export backups regularly. Do not store passwords, financial account credentials, or sensitive personal information.
