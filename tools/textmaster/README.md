# TextMaster v1.0

Browser-based text utility suite: live character/word/sentence/read-time counts, uppercase/lowercase/title/sentence case, whitespace cleanup, remove blank lines, trim lines, deduplicate/sort/reverse/number lines, find-and-replace, simple two-text comparison, clipboard copy and TXT download. Responsive layout and dark mode. Processing is local; no upload.

Note: comparison is a basic length/count comparison, not a word-level diff. Clipboard access depends on browser permissions/HTTPS.
