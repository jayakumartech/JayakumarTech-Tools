# AudioKit v1.0

Browser-based audio utility. Import multiple supported audio files, reorder tracks, trim each track, adjust volume and playback speed, set fade-in/fade-out, preview tracks, join them sequentially, and export WAV (mono/stereo, 22.05/44.1/48 kHz). Includes dark/light theme.

Files are decoded and processed locally in browser memory. Export is uncompressed PCM WAV. MP3/AAC export is not included. Large files may use substantial RAM and fail on mobile. Browser codec support varies. No upload or server storage.
