# India Unit Converter v1.0

Mobile-friendly offline unit converter for JayakumarTech Tools.

## Categories
Length, Weight, Area, Volume, Speed, Time, Temperature and Data.

## Features
- Live conversion as you type
- Swap source and target units
- Common quick conversions
- India-relevant land area unit: cent (1/100 acre)
- Copy result, reset and dark/light theme
- Offline browser operation; no data upload

## Install
Extract this folder to `tools/india-unit-converter/`.

## Notes
Uses standard metric and international conversion factors. Regional land measures such as kuzhi, ground, bigha and local variants are intentionally excluded because their values vary by region. Data units use decimal KB/MB/GB/TB (1 KB = 1,000 bytes).
