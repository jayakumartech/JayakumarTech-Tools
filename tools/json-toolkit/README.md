# JSON Toolkit v1.0

A mobile-friendly, client-side JSON utility for JayakumarTech Tools.

## Features
- JSON syntax validation with parser error messages
- Pretty formatting and minification
- Expandable/collapsible object and array tree viewer
- Sample JSON, copy output and `.json` download
- Character counters and dark/light theme
- Local browser processing; no server upload

## Install
Extract this folder to `tools/json-toolkit/` and open `index.html`.

## Limitations
Validation follows the browser's native JSON parser. The tool does not perform JSON Schema validation, API calls, or automatic repair of malformed JSON.
